# POLLOS-SENA
Proyecto Pollos con Node.js, MySQL, JavaScript
05/10/2026 se creo los requisitos funcionales 
1. Que el software debe mostrarle al cliente los productos de pollo disponibles

A. Debe existir un ente Administrador que pueda crear al usuario cliente.

B. El cliente puede crear su propia cuenta.

C. El usuario cliente debe poder validarse para comprobar que está registrado y así poder visualizar los productos de pollo disponibles.

D. Debe existir una vista para que el Administrador cree los productos de pollo.

E. Debe existir una vista que permita validar los productos de pollo registrados y disponibles.

2. La información y disponibilidad de esos productos

A. El cliente puede visualizar la información y disponibilidad de los productos de pollo.

B. El Administrador puede visualizar la información y disponibilidad de los productos de pollo.

C. El trabajador puede visualizar la información y disponibilidad de los productos de pollo.

D. El trabajador puede editar la información de los productos de pollo.

E. El trabajador puede eliminar productos de pollo.

F. El Administrador puede editar la información de los productos de pollo.

G. El Administrador puede eliminar productos de pollo.

RF01: El sistema debe permitir al administrador crear una cuenta de un nuevo cliente.
RF02: El sistema debe permitir al nuevo cliente crear su propia cuenta.
RF03: El sistema debe permitir al nuevo cliente ingresar al sistema mediante LOGIN.
RF04: El sistema debe permitir al administrador crear una cuenta para un nuevo trabajador.
RF05: El sistema debe permitir al nuevo trabajador ingresar al sistema mediante LOGIN.
RF06: El sistema debe permitir al cliente visualizar los productos de pollo disponibles para la venta.
RF07: El sistema debe permitir al administrador visualizar los productos de pollo disponibles para la venta.
RF08: El sistema debe permitir al trabajador visualizar los productos de pollo disponibles para la venta.
RF09: El sistema debe permitir al trabajador editar la información de los productos de pollo.
RF10: El sistema debe permitir al trabajador eliminar productos de pollo.
RF11: El sistema debe permitir al administrador editar la información de los productos de pollo.
RF12: El sistema debe permitir al administrador eliminar productos de pollo.
RF13: El sistema debe permitir al administrador eliminar un trabajador.
RF14: El sistema debe permitir al administrador eliminar un cliente.
